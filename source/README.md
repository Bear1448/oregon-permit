# Official Oregon Driver Manual source

- Official PDF: [https://www.oregon.gov/odot/forms/dmv/37.pdf](https://www.oregon.gov/odot/forms/dmv/37.pdf)
- Local copy: `oregon-driver-manual-37.pdf` (downloaded from that URL)
- Extracted text: `manual.txt`, used to verify every numeric fact and page cite

The printed cover and page footers are the **2026–2027** edition (112 pages, published December 17, 2025). The PDF’s internal metadata title still says “2024-2025”; the content is the current 2026–2027 manual. Printed page numbers in the footer are the `manual.page` values used in the question bank (maximum 96 in the study chapters).
