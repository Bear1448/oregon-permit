# Sign image sources

All bundled sign artwork is from the U.S. Federal Highway Administration’s Standard Highway Signs / MUTCD, obtained via Wikimedia Commons files tagged **PD-USGov-MUTCD**. These designs are public domain U.S. government work.

No Interstate shield (or other FHWA-owned marks such as MUTCD I-2 or M1-5) is included.

Each file below is stored at `public/signs/` and, when used in a question, is cited on the question’s `signImage` record (`source: wikimedia-pd-usgov-mutcd`).
